# AidData Africa 3D Map

Interactive SVG visualization of Chinese development finance to Africa using AidData 3.0 records.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is generated in `dist/`.

## Deployment

This project is configured for static deployment on Vercel and Netlify.

- Build command: `npm run build`
- Output directory: `dist`
